# AperolSpritz Desktop

Простой Windows-монитор для нескольких измерителей AperolSpritz. Требуется Python 3.9 или новее; интерфейс использует входящие в Python `tkinter` и SQLite.

## Установка и запуск

```powershell
cd desktop
python -m pip install -r requirements.txt
python app.py
```

Нажмите **Добавить устройство**, задайте понятное имя и IP-адрес. Каждое активное устройство опрашивается независимо: недоступность одной установки не блокирует остальные и не замораживает GUI.

## Данные

Настройки и база хранятся в пользовательском каталоге:

```text
%APPDATA%\AperolSpritz\settings.json
%APPDATA%\AperolSpritz\measurements.db
```

SQLite — источник истины. Событие уникально по `(device_id, boot_id, measurement_seq)`, поэтому повторный polling не создаёт дубликаты. В БД сохраняются локальное и UTC-время компьютера, имя/IP установки, результат, параметры калибровки и технические координаты.

**Экспорт Excel** создаёт оформленный `.xlsx` с листом «Измерения». **Экспорт CSV** создаёт файл UTF-8 с BOM и разделителем `;`. Оба экспорта включают всю историю из SQLite, а не только видимые строки таблицы.

## Если устройство offline

- проверьте IP и доступность устройства в той же сети;
- откройте `http://<IP>/` в браузере;
- убедитесь, что firewall не блокирует локальные HTTP-запросы Python;
- после восстановления сети приложение переподключится автоматически.

При кратком разрыве приложение забирает пропущенные события из RAM ring buffer ESP. Предупреждение «Часть измерений могла быть пропущена» означает, что запрошенные события уже были вытеснены из буфера устройства; это не ошибка измерителя.
