AperolSpritz Desktop
====================

1. Полностью распакуйте архив.
2. Запустите AperolSpritz.exe.
3. Добавьте IP-адреса одного или нескольких измерителей.
4. Настройки и история находятся в %APPDATA%\AperolSpritz.
5. Файлы Excel и CSV создаются кнопками экспорта.
6. Не удаляйте каталог _internal и не переносите отдельно один EXE.

Подтверждённая целевая платформа: Windows 11 x64.
Для запуска установленный Python и доступ в интернет не требуются.
