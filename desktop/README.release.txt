AperolSpritz Desktop v1.1.0
===========================

1. Полностью распакуйте архив.
2. Запустите AperolSpritz.exe.
3. Добавьте IP-адрес измерительного устройства.
4. Подробная инструкция находится в:
   docs\Руководство оператора.pdf

Не удаляйте папку _internal.
Для запуска не требуется установленный Python.
